# [구동안내서] 법령안편집기 — 규정 제·개정 에이전트

2026년 공공 AI 대전환 챌린지 · 세션2 지정과제 ③ 규정 제·개정 에이전트 · 안양도시공사

## 1. 실행 환경

| 항목 | 내용 |
|---|---|
| OS | Windows 10 / 11 (64비트) |
| 설치 | **필요 없음** — `법령안편집기` 폴더를 통째로 복사해 `법령안편집기.exe` 실행 |
| 권장 사양 | 메모리 4GB 이상, 디스크 여유 300MB, 화면 1600×900 이상 |
| 인터넷 | AI API(Claude 등)·국가법령정보 Open API 사용 시 필요. **AI·법령 API 없이도 핵심 기능(개정문·대비표·검사·규정집 분석)은 동작** |
| 선택 | 한컴오피스 한글 — HWP(97~) 형식 저장 시. HWPX 저장은 한글 없이 가능 |

## 2. 설치·실행 절차

1. 공공 GitLab 저장소의 `dist/법령안편집기` 폴더(또는 릴리스 zip)를 내려받아 원하는 위치에 둡니다.
2. `법령안편집기.exe` 를 실행합니다. 시작 화면 뒤 3초 안팎에 주 화면이 열립니다.
   - Windows SmartScreen 경고가 나오면 [추가 정보] → [실행].
3. (선택) **법령 API**: 상단 `≡` → [설정] → '법령 API OC'에 open.law.go.kr 에서 승인받은 OC(가입 이메일 아이디) 입력.
4. (선택) **AI API**: [AI 도우미] 탭 → [AI 설정] → API 키 입력 → [연결 시험].
5. 연결 확인(화면 없이): 명령창에서 `법령안편집기.exe --ai-selftest` 실행 →
   `%APPDATA%\LawEdit\ai_selftest.txt` 에 `AI OK …`, `LAW OK …` 가 기록됩니다.

## 3. LLM 연결 설정 (모델 비종속 — API 교체형)

| 연결 방식 | 설정 값 |
|---|---|
| Claude (Anthropic API) — 기본 | 모델 `claude-opus-5-5`, API 키 |
| OpenAI 호환 API | 서버 주소(…/v1), 모델 이름, API 키 — OpenAI, Google Gemini(호환 주소), **행정안전부 AI 공통기반**, 기관 내부 API 서버 |

- 교체 방법: [AI 도우미] → [AI 설정]에서 '빠른 선택' 또는 연결 방식·주소·모델만 바꾸면 모든 AI 기능이 그대로 동작합니다(코드 수정 불필요).
- 구조: `lawedit/ai/llm.py` 의 공통 함수 `complete()` 하나로 모든 AI 기능이 호출되며, 연결 방식(provider)만 갈아 끼웁니다.
- **AI는 초안만 작성**하고, 조 번호 부여·인용 정정·개정문·신구조문대비표·오류 검사는 규칙 엔진이 다시 만들고 검증합니다. 모델이 바뀌어도 결과 서식과 검증 품질은 같습니다.
- 키 보호: API 키는 Windows 보안 저장소(DPAPI)로 암호화해 `%APPDATA%\LawEdit\settings.json` 에만 저장(같은 PC·같은 사용자만 복호화). 프로그램 폴더·저장소에는 키가 없습니다. 환경변수 `LAWEDIT_API_KEY` 로도 지정할 수 있습니다.

## 4. 모의데이터 안내 (저장소 `sample/`)

| 파일 | 용도 | 투입 방법 |
|---|---|---|
| `sample/안양도시공사 규정집(20260507).pdf` | 공사 누리집 공개 규정집(규정 73개) | [규정집 분석] → [규정집 PDF 열기] (처음 1회 약 20초, 이후 즉시) |
| `sample/현행_안양도시공사_인사규정.txt` | 개정 대상 현행 규정 | [홈] → [현행추가] |
| `sample/개정의도_예시.txt` | AI 개정안·제정안 입력 예시 | 문장을 복사해 입력창에 붙여 넣기 |
| `sample/개정문_예시.txt` | 개정문 → 개정 본문 적용 시연 | [개정도구] → [개정문분석]에 붙여 넣기 |

모두 공개 자료이거나 직접 작성한 문장이며 개인정보·비공개 정보는 없습니다.

## 5. 기능 사용 순서 (핵심 흐름)

**흐름 1. 개정 의도 → 개정안·신구조문대비표 (기본 기능: 개정)**
1. [규정집 분석]에서 규정집 PDF를 열고, 트리에서 '인사규정' 선택 → [이 규정 개정하기]
   (또는 [홈] → [현행추가] → `sample/현행_안양도시공사_인사규정.txt`)
2. [AI 도우미] → [AI 개정안] → 개정 의도 입력(예시 1) → [AI 초안 만들기]
3. 미리보기에서 AI 초안, **엔진 검증 결과**(번호·인용·부호 오류), 개정문, 신구조문대비표 확인 → [개정안에 적용]
4. [현행/개정/개정문]·[신ㆍ구조문대비표] 탭 확인 → [홈] → [입법예고문]·[관보게재문]·[제개정이유] 초안 생성
5. [한글로 저장]·[개정문 내보내기]·[대비표 내보내기] → HWPX/HWP/PDF

**흐름 2. 영향 조항·오류 검토 (선택 기능)**
1. 흐름 1의 개정안 상태에서 [규정집 분석] 탭 → [개정 영향분석]: 함께 고쳐야 할 상위·하위·관련 규정 조문 목록(명시적 인용 / 같은 기구 언급 / 같은 명칭 사용 / 같은 주제)
2. 도우미 [타법개정] → [타법개정 문안]: 바뀐 명칭('경영기획본부장')을 쓰는 다른 규정을 찾아 부칙 「다른 규정의 개정」 문안 생성 → [부칙에 넣기]
3. [상충 검사]: 상·하위 규정의 수치 불일치, 없는/삭제된 조문 인용, 폐지 규정 인용, 직제에 없는 조직명 → 행 선택 후 [선택 건 AI 검토]
4. [상위법 대조]: 인용한 국가 법령을 Open API로 조회해 조문 존재·삭제 여부와 **법령명 변경**(예: 「민원사무처리에 관한 법률」→「민원 처리에 관한 법률」)을 찾아 줌

**흐름 3. 제정안 작성 (기본 기능: 제정)**
1. [AI 도우미] → [AI 제정안] → 규정명·종류·제정 목적·위임 조항 입력(예시) → [AI 초안 만들기]
2. 조문 체계 초안과 엔진 검증 결과 확인 → [편집기로 보내기] → [조문 검사]·[용어 검사]로 다듬기

## 6. 알려진 제약 사항

- AI 초안은 참고용이며 담당자 검토가 필요합니다(엔진이 형식 오류는 잡지만 정책 판단은 하지 않음).
- AI API 사용 시 입력 내용이 API 회사 서버로 전송됩니다. 입법예고 전 비공개 내용은 기관 보안지침에 따르십시오.
- 규정집 PDF 자동 분리는 '쪽 머리글(규정명·쪽번호)과 분류코드 목차'가 있는 형식을 기준으로 합니다. 다른 형식은 개별 규정을 HWP/HWPX/TXT로 불러와 사용합니다.
- 원본 법령안편집기(.law3) 파일은 직접 읽지 못합니다(원본에서 HWP/HWPX로 저장 후 불러오기).
- 상충 검사는 규칙 기반 판정이라 '낮음' 수준에는 참고용 결과가 섞일 수 있습니다([선택 건 AI 검토]로 확인).
- 재배포가 제한되는 구성요소는 없습니다(`THIRD_PARTY_LICENSES.md`). 화면은 Qt(LGPL-3.0)를 동적 링크로 사용합니다.

## 개발 경위 요약

**문제 인식** — 규정을 개정할 때마다 신구조문대비표·개정문·부칙을 손으로 만들고, 조 번호가 바뀌면 그 조를 인용한 다른 조문과 다른 규정을 눈으로 찾아야 했습니다. 공사 규정 73개는 조례 › 정관 › 규정 › 시행내규로 얽혀 있어 한 조문을 고치면 어디까지 영향이 가는지, 상위 규정·법령과 어긋나지 않는지 확인하기 어려웠습니다. 법제처 법령안편집기는 국가 법령 중심이라 기관 규정 체계 분석은 지원하지 않습니다.

**접근 방식** — ① 법령안편집기의 핵심 기능(개정문·대비표·조문 검사·용어 검사·입법예고문·관보게재문)을 규칙 엔진으로 직접 구현하고, ② 규정집 전체를 조문 단위로 구조화해 상·하위 체계·인용 관계·영향·상충을 분석했으며, ③ 생성형 AI는 '개정 의도 → 조문 초안' 같은 글쓰기에만 쓰고 결과는 항상 규칙 엔진이 다시 검증하게 했습니다. AI 연결은 API 교체형으로 만들어 특정 모델에 묶이지 않습니다. 개발 전 과정은 생성형 AI 코딩 도구(Claude Code)로 직접 수행했습니다.

**검증** — 공개 규정집 73개 규정에 무작위 개정을 가해 개정문을 만들고 다시 현행에 적용하는 왕복 시험(편집기 재분석 경로 포함) 기본 개정 1,314건 전부 일치, 맞바꾸기·번호 일괄 정리 등을 더한 경우 1,309건 일치. 실제 규정집에서 오탈자 인용("제47항제1항"), 개명된 상위 법령 인용 등을 찾아냈습니다.
