# 법령안편집기 클론 (LawEdit) 요구사항

## 1. 원본(법제처 법령안편집기 3.1) 기능 매핑 — 로그인 제외 전부
| 원본 메뉴 | 구현 |
|---|---|
| 파일: 신규/불러오기/저장 | `.lawj`(JSON) 저장, TXT/HWPX/PDF 불러오기 |
| 문서처리: 입법예고문/관보게재문 | core/docs.py |
| 한글도구 | HWPX 내보내기(자체 생성), 한글 설치 시 HWP/PDF 변환(COM) |
| 법령검색 | 국가법령정보 Open API (law/ordin) |
| 검색도구: 찾기/바꾸기 | UI |
| 개정도구: 개정분석(필수)/맞교환/삭제/조문이동/일괄변경/이동표시/전문개정/자구재설정 | core/amend.py, core/numbering.py |
| 조문검토: 조문 검사/용어 검사/스타일링 | core/checks.py, core/dictionary.py |
| 일괄업무: 일괄처리 | 폴더 단위 검사/변환 |
| 현행/개정/개정문, 현행/개정/대비표, 개정문(본문), 신ㆍ구조문대비표, 법령안 탭 | UI |
| 개정문분석 (개정문 → 개정본문 적용) | core/amend.py |
| 타법개정 / 타법목록 추출 | core/otherlaw.py |
| 별표/서식 목록, 별지신설/이동/삭제 | model.Appendix |
| 용어관리/용어추가 | 사용자 사전 |
| 조문 입법례 / 입법례 또는 표준문장 / 연관정보 | 표준문장 라이브러리 + 규정집/API 검색 |
| 현행추가 / 개정취소 / 목록삭제 / 일괄추가·삭제 | UI |

## 2. 추가 기능 — 안양도시공사 규정집 분석
1. 규정집 PDF → 규정별 분리, 조문 구조화, 제·개정 연혁
2. 상·하위 체계: 조례 > 정관 > 규정 > 시행내규/내규 (코드 0202 → 020201) + 인용(「」, "규정 제N조") 그래프
3. 영향분석: 어떤 규정(조문)을 바꾸면 함께 바뀌어야 할 상위·하위·관련 규정 조문 목록
4. 상충검사: 상·하위(및 인용 관계) 규정 간 수치(인원·기간·금액·비율·연령) 불일치, 없는 조문 인용, 폐지 규정 인용, 상위법(법령 API) 조문 대조

## 3. 기술
Python 3.11 + PySide6, PyMuPDF, PyInstaller(onefile .exe, Windows에서 빌드)
