# 법령안편집기 — 규정 제·개정 에이전트

공공기관 규정(사규)을 고칠 때 필요한 **개정문 · 신ㆍ구조문대비표 · 부칙 · 입법예고문**을 자동으로 만들고,
규정 하나를 고치면 **함께 고쳐야 할 상위·하위 규정과 상충하는 조문**까지 찾아 주는 Windows 데스크톱 프로그램입니다.

> 2026년 공공 AI 대전환 챌린지 · 세션2 지정과제 ③ **규정 제·개정 에이전트** 출품작 (안양도시공사)

![신ㆍ구조문대비표](docs/images/compare_table.png)

## 왜 만들었나

- 규정을 개정할 때마다 대비표·개정문·부칙을 손으로 만들고, 조 번호가 바뀌면 그 조를 인용한 다른 조문과 다른 규정을 눈으로 찾아야 했습니다.
- 공사 규정 73개는 **조례 › 정관 › 규정 › 시행내규**로 얽혀 있어, 한 조문을 고치면 어디까지 영향이 가는지, 상위 규정·법령과 어긋나지 않는지 확인하기 어렵습니다.
- 법제처 「법령안편집기」는 국가 법령 중심이라 기관 규정 체계 분석은 지원하지 않습니다.

## 주요 기능

### 1. 개정 · 제정 (법령안편집기 기능 + AI 초안)
| 기능 | 설명 |
|---|---|
| **AI 개정안** | 개정 의도를 문장으로 적으면 AI가 조문 수정안을 쓰고, 엔진이 개정문·대비표를 다시 만들고 검증 |
| **AI 제정안** | 제정 목적·상위 규정 위임 조항 → 조문 체계와 규정 초안 |
| 개정문 자동 생성 | 현행↔개정안 비교 → 법제처 입안 기준 문형 (`제8조제2항 중 “5명 이상 7명”을 “7명 이상 9명”으로 한다.`, `각각`, 신설·삭제·제목 변경·조 이동) |
| 신ㆍ구조문대비표 | `(생 략)` / `(현행과 같음)` / 밑줄 표시 — HWPX·HWP·PDF·HTML로 내보내기 |
| 개정문분석 | 개정문을 현행에 적용해 개정 본문 생성 (역방향) |
| 개정도구 | 조문 신설(가지조)·삭제·이동·맞교환·번호 일괄 정리·전문개정 — **본문 인용 번호 자동 정정** |
| 조문 검사 · 용어 검사 | 번호 순서, 없는 조문 인용, 부호 짝, 법령 용어·띄어쓰기 (원본 법령안편집기 사전이 설치돼 있으면 함께 사용) |
| 문서 생성 | 입법예고문, 관보(발령) 게재문, 제·개정 이유 및 주요내용 |

### 2. 규정집 분석 (추가 기능)
| 기능 | 설명 |
|---|---|
| 규정집 구조화 | 규정집 PDF 1권 → 규정 73개 · 조문 2,219개로 분리, 분류코드로 상·하위 트리 구성 |
| **개정 영향 분석** | 바꾸는 조문을 인용하는 조문, 같은 기구·같은 명칭을 쓰는 조문, 같은 주제의 상·하위 조문 |
| **명칭 일괄 개정 · 타법개정** | 예: ‘경영기획본부’ → 11개 규정 15곳을 찾아 기준 규정 개정 + 부칙 「다른 규정의 개정」 ①~⑩ 자동 작성 |
| **상충 검사** | 상·하위 규정 수치 불일치, 없는·삭제된 조문 인용, 폐지 규정 인용, 상위 개정 미반영, 직제에 없는 조직명 + **AI 검토** |
| **상위법 대조** | 인용한 국가 법령을 국가법령정보 Open API로 조회 — 조문 존재·삭제, **법령명 변경 탐지** (예: 「민원사무처리에 관한 법률」 → 「민원 처리에 관한 법률」) |

## 설계 원칙 — AI는 초안만, 검증은 엔진이

```
개정 의도 ──▶ AI(LLM) 조문 초안 ──▶ 규칙 엔진 ──▶ 개정문 · 대비표 · 부칙
                                       │         (조 번호 부여, 인용 정정,
                                       │          입안 기준 문형, 오류 검사)
규정집 · 국가법령 API ──────────────────┘
```

- **모델 비종속(API 교체형)**: Claude(Anthropic) 또는 OpenAI 호환 API(OpenAI·Google Gemini·행정안전부 AI 공통기반·기관 내부 서버)를 설정에서 바꿔 끼웁니다. 모든 AI 기능은 `lawedit/ai/llm.py` 의 `complete()` 하나를 거칩니다.
- **AI 없이도 동작**: 개정문·대비표·검사·규정집 분석은 AI·인터넷 없이 동작합니다.
- AI가 의도와 다른 표기를 쓰거나(오타를 몰래 고침 등), 현행 규정에 없는 명칭을 바꾸려 하면 경고합니다.

## 설치 · 실행

### 실행 파일 (Windows 10/11, 설치 불필요)
1. [Releases](../../releases)에서 `법령안편집기_v1.0.zip` 을 내려받아 압축 해제
2. `법령안편집기\법령안편집기.exe` 실행
3. 시연용 데이터: 저장소의 `안양도시공사 규정집(20260507).pdf` → [현행추가] 또는 [규정집 분석]에서 열기, 입력 예시는 [`sample/`](sample/README.md)

### 소스에서 실행
```bash
pip install PySide6 pypdf anthropic requests olefile pywin32   # Python 3.11
python -m lawedit            # 실행
python -m pytest tests       # 시험
build\build_exe.bat          # Windows 실행 파일 빌드 (PyInstaller, 폴더형)
```

## 설정 (선택)

| 항목 | 위치 | 비고 |
|---|---|---|
| 국가법령정보 Open API **OC** | `≡` → [설정] | [open.law.go.kr](https://open.law.go.kr)에서 신청·승인받은 값 (법령검색·상위법 대조) |
| AI API 키 | [AI 도우미] → [AI 설정] | 연결 방식·모델·주소를 바꿔 끼우는 곳. [연결 시험] 제공 |

연결 확인(화면 없이): `법령안편집기.exe --ai-selftest` → `%APPDATA%\LawEdit\ai_selftest.txt`

### API 키 보호
- 키는 **Windows 보안 저장소(DPAPI)로 암호화**해 `%APPDATA%\LawEdit\settings.json` 에만 저장합니다. 같은 PC·같은 사용자만 풀 수 있습니다.
- 저장소·실행 파일·배포 폴더에는 키가 들어가지 않습니다. 환경변수 `LAWEDIT_API_KEY` 로도 줄 수 있습니다.
- 오류 메시지에서 키를 가리고, 설정 화면에는 앞뒤 일부만 표시합니다.
- [`tools/secret_scan.py`](tools/secret_scan.py) 로 키 유출을 검사하며, 커밋·푸시 훅과 시험에서 자동 실행됩니다.
- AI API를 쓰면 입력한 개정 의도와 규정 본문이 API 회사 서버로 전송됩니다. 입법예고 전 비공개 내용은 기관 보안지침을 따르십시오.

## 검증

- 공개 규정집 73개 규정에 무작위 개정을 가해 개정문을 만들고, 그 개정문을 다시 현행에 적용해 원래 개정안과 비교하는 **왕복 시험 657건 전부 일치** (`tests/fuzz_amend.py`)
- 단위 시험 21개 (`tests/`) — 파서, 개정문 문형, 대비표, 인용 정정, 규정집 체계·영향·상충, 키 유출 검사
- 실제 규정집에서 찾아낸 예: 오탈자 인용(“제47항제1항제7호”), 조 번호 중복 오타(“제84조제85조”), 개명된 상위 법령 인용 4건

## 구성

```
lawedit/
  core/    문서 모델·파서, 개정문·대비표(amend), 조문번호(numbering), 인용(refs),
           조문·용어 검사(checks, dictionary), 문서 생성(docs), 파일 입출력(HWP·HWPX·PDF),
           국가법령 Open API(lawapi), 타법개정(otherlaw), 표준문장(standards)
  regs/    규정집 PDF 분리(regbook), 체계·영향·상충·상위법 대조(analysis)
  ai/      API 교체형 LLM 연결(llm), 개정·제정·상충 검토 에이전트(agent)
  ui/      PySide6 화면 (메인 창, 규정집 분석 창, AI 도우미, 대화상자, 테마)
tests/  sample/  docs/  tools/  build/
```

자세한 구동 방법: [`docs/구동안내서.md`](docs/구동안내서.md)

## 자료 · 라이선스

- `안양도시공사 규정집(20260507).pdf` 는 안양도시공사 누리집에 공개된 규정집입니다. 국가 법령은 국가법령정보 공동활용 Open API로 실시간 조회합니다.
- 사용한 오픈소스와 라이선스: [`THIRD_PARTY_LICENSES.md`](THIRD_PARTY_LICENSES.md) (재배포 제한 구성요소 없음)
- 법제처 「법령안편집기」의 프로그램·사전은 포함하지 않습니다. 해당 프로그램이 PC에 설치돼 있으면 실행 시 그 용어 사전을 읽어 씁니다.
- 개발: 생성형 AI 코딩 도구(Claude Code)를 사용해 직접 개발했습니다.
